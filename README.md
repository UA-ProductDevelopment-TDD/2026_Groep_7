## Het project

We analyseren, verbeteren en breiden een open-source robot uit: de **Petoi Bittle X** met **BiBoard V1**. Het concept is nog in ontwikkeling: we werken aan minstens drie kandidaten en kiezen er één na het consult. Eén kandidaat is de kippenhok-robot (`concept/kandidaten/kippenhok.md`); de andere volgen. Stand: `concept/CONTEXT.md`.
