Mondeling werd een maximum van 2 personen per subteam genoemd `[mondeling, niet bevestigd]`.

## Managementrollen

De slides geven twee lijsten. Het team koos de lijst "Teamstructuur" met zes rollen, elk bij één persoon (`BESLUITEN.md`, D005). De Technical Manager staat alleen op de andere lijst en is dus niet gekozen.

| Rol | Verantwoordelijkheid volgens de slides | Op slide | Naam |
|---|---|---|---|
| Project Manager | procescoördinatie, planning, communicatie docenten | beide | Wannes |
| Technical Manager | inhoudelijke integratie, technische afstemming tussen subteams | alleen "Rollen" (template) | niet gekozen (D005) |
| GitHub Manager | setup GitHub, coördinatie HW/EL/UX-teams voor documentatie | beide | Jolan (`JolanDijkmans`); draaiboek: `_config/git-master.md` |
| Robot (Bittle) Manager | welzijn van de robot, uitlenen aan subteams, controle, kalibratie, opslag, transport | beide | Arno |
| Module Manager | uitlenen, bestellen en beheren van extra elektronicamodules (sensoren, actuatoren, IC's) | alleen "Teamstructuur" | Ward |
| Simulation/test Manager | de digital twins: virtuele versies van robot en omgeving om concepten en animaties veilig te testen | alleen "Teamstructuur" | Joren (zit in `t3-ux-ui`, niet in `t2-hw-sim`: stem de simulatie af met Wannes en Arno) |
| Presentatie Manager | presentaties en filmpje | beide | Ben |

Teaminfo uit de bijgewerkte lijst van de docenten (D005). Wij zijn team 7; de repo staat op https://github.com/UA-ProductDevelopment-TDD/2026_Groep_7 (D007). Een teamnaam is er niet `[ONBEKEND]`. Welke GroveKit en welke Bittle het team heeft: `SYSTEEM.md`.
